# Run Both Projects Side by Side

## Terminal 1 - Original Analyser (port 3000)
```bash
cd bird-flight-dashboard
npm run dev
```
Opens at http://localhost:3000

## Terminal 2 - New SMS (port 3001)
```bash
cd bird-flight-dashboard-sms
npm run dev
```
Opens at http://localhost:3001

## Compare side by side
Open both URLs in two browser windows or tabs.
The SMS version shows a red "SMS v2 · PORT 3001" pill at the top so you always know which one you're looking at.
